# Ebru Beauty Güzellik Merkezi – web sitesi

Astro ile hazırlanan statik site; GitHub Pages'e GitHub Actions ile yayınlanır.

- İletişim bilgileri, hizmetler ve test soruları: `src/data/site.js`
- Adres ve Google Haritalar linki: `ADDRESS` ve `MAPS_URL` (boşken sitede gizli / işletme adıyla arama açılır)
- Fotoğraflar: `public/img/<ad>-800.webp`, `-1600.webp` ve `.jpg`
- Logo: `public/brand/logo-full.svg`, kelebek: `src/components/butterfly.svg`

Yerelde: `npm install && npm run dev`
